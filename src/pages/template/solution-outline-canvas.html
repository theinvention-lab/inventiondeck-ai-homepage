3. Solution Outline Canvas

솔루션의 핵심 기능과 가치를 중심으로 구조화합니다.

Solution Tagline

제품/서비스가 고객에게 제공하는 핵심 가치를 1~2문장으로 간단하게 표현

✨
예: 'AI가 만드는 당신만의 학습 로드맵'

Key Features (핵심 기능)

제품/서비스의 핵심적인 기능, 특징

✨
예: 맞춤형 커리큘럼 생성, 실시간 피드백, 학습 진행 상황 분석

Customer Values (고객에게 주는 가치)

이를 통해 고객이 얻는 가치

✨
예: 학습 효율 극대화, 시간 절약, 목표 달성 지원

Key Requirements (필요 조건)

초기 실행 단계에서, 해당 기능/특징을 구현하기 위해 가장 핵심적으로 수행하거나 확보해야 하는 것들은?

✨
예: AI 알고리즘 개발, 양질의 학습 데이터 확보, 사용자 친화적 UI/UX

Hurdles (실행 시 장벽)

실제 실행시 예상되는 어려움이나 극복해야 할 요소는?

✨
예: 높은 초기 개발 비용, 사용자 데이터 프라이버시, 시장 경쟁 심화

※ 실제 인벤션덱AI 화면을 옮긴 예시입니다. 서비스에서는 각 칸을 직접 작성하거나 ✨ 버튼으로 AI 초안을 받을 수 있어요.
