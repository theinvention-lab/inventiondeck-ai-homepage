How it works

복잡하지 않아요.
누구나 아이디어를 만들 수 있어요!

  1. 카드 살펴보기다양한 카테고리의 카드들을 탐색하며 관심가는 키워드의 상세내용을 확인해요
  2. 카드덱 저장하기나중에 참고하거나 사용하고 싶은 카드의 하트를 눌러 카드덱으로 저장해요
  3. 카드 선택하기원하는 카드를 직접 고르거나 입력한 정보를 기반으로 AI로부터 카드 추천을 받아요
  4. 아이디어 생성하기선택한 카드 조합으로 AI가 새로운 비즈니스 아이디어를 제안해요
  5. 아이디어 보관하기마음에 드는 아이디어를 나만의 아이디어 보관함에 저장해요
  6. 아이디어 구체화하기비즈니스 템플릿을 활용해 마음에 드는 아이디어를 구체적인 형태로 발전시켜요
  7. 아이디어 저장하기아이디어를 저장하고 필요할 때 꺼내볼 수 있도록 관리해요
