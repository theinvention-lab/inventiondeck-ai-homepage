카드 살펴보기

카드 살펴보기는 InventionLab이 큐레이션한 다양한 아이디어 카드를 탐색할 수 있는 단계입니다. 카드는 총 6개의 카테고리로 구성되어 있으며 클릭 시 상세 설명과 실제 기업 사례를 확인할 수 있어 다양한 아이디어 발상에 도움을 받을 수 있습니다.

사용 방법 그림과 함께 각 번호를 따라가 보세요!

1

카테고리 선택하기

화면 상단에서 원하는 카테고리를 선택하면 해당 카테고리의 카드만 골라서 볼 수 있어요.

  • All전체 카드
  • Theme산업별 테마
  • Target타겟 세그먼트
  • Trend주목받는 트렌드
  • Tech적용가능한 기술
  • Feature비즈니스 피쳐
  • Revenue수익 모델 유형
2

좌측부터 순서대로 확인하세요!

⌨️ 키워드 입력하기생각 중인 키워드나 간략한 아이디어를 입력하면 AI가 해당 주제에 적합한 카드 조합을 자동으로 추천해드려요.
🔁 카드 랜덤 섞기스크롤이 너무 길다면? 버튼을 눌러 카드를 랜덤으로 셔플해 새로운 시각에서 탐색해보세요.
🔎 카드 검색하기자세한 설명이나 기업 사례를 알고 싶은 키워드가 있다면, 검색창을 활용해 해당 카드를 빠르게 찾아볼 수 있어요.
3

카드 상세 보기 및 저장

원하는 카드를 클릭하면 한 줄 요약, 카드 설명, 실제 기업 사례를 확인할 수 있어요. 또한 카드 내의 아이콘을 통해 다음 기능을 사용할 수 있어요.

  • 🖤 아이콘 : 마음에 드는 카드를 [Card Deck] 폴더에 저장
  • ➕ 아이콘 : 해당 카드를 아이디어 생성 조합에 추가

사용 팁

카드 랜덤 섞기 기능을 통해 창의력을 자극해보세요!

생각이 막혔을 때, 갑자기 보이는 카드가 오히려 새로운 연결고리를 만들어줄 수 있어요. 무작위 추천에서 나온 '의외의 카드'를 아이디어 씨앗으로 사용해보세요!

하트 아이콘을 적극 활용해 나만의 카드 포트폴리오를 만들어요!

나중에 조합하려는 카드, 흥미로운 카드, 마음에 드는 카드 등 마이 카드덱을 만들어두면 '나만의 인사이트 저장소'로 진화시킬 수 있어요!

Use Cases를 유심히 읽어보세요!
