AI 아이디어 생성하기

AI 아이디어 생성하기는 사용자가 선택한 카드 조합을 기반으로 AI가 비즈니스 아이디어를 자동 생성해주는 단계입니다. AI는 선택한 카드 키워드를 기반으로 실제 사업화 가능성까지 고려한 아이디어를 제안합니다.

사용 방법 그림과 함께 각 번호를 따라가 보세요!

1

좌측부터 순서대로 확인하세요!

🃏 다시 카드 선택하기선택된 카드 조합을 수정하고 싶다면 [back to card selection]을 클릭해 카드 탐색 단계로 넘어갈 수 있어요. 이때 생성된 아이디어는 따로 저장되지 않으니, 마음에 드는게 있다면 북마크를 선택해 저장해주세요!
💡 아이디어 재생성하기생성된 3가지 아이디어가 마음에 들지 않는다면 새롭게 생성할 수 있어요.
🔠 추가 키워드 입력하기생성된 아이디어 확인 후, 원하는 추가 키워드가 있다면 체크박스를 클릭해 추가해주세요! 입력한 키워드를 추가해 AI가 새로운 아이디어를 생성해요.

키워드 입력 형식 예시 (아래의 케이스 모두 가능해요!)

  • MZ세대, 친환경 ',' 사용
  • MZ세대 친환경 공백 사용
  • MZ세대/친환경 '/' 사용

사용 팁

같은 카드 조합으로 2~3회 정도 재생성해봐요!

AI는 조합은 같아도 매번 다른 관점의 아이디어를 제안할 수 있어요. 2~3회 정도 재생성해보며 인사이트를 발견해봐요!

추가 키워드를 작성할 때는 구체적으로 작성해봐요!

구체적인 조건을 입력할 수록 아이디어의 품질이 좋아질 수도 있어요.
